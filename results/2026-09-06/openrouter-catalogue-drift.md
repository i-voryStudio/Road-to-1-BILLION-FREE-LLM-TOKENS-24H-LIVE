# OpenRouter catalogue drift, measured 2026-09-06

Two readings of the same public endpoint, `https://openrouter.ai/api/v1/models`,
taken hours apart on a single afternoon. No API key is needed to reproduce this:

```
curl -s https://openrouter.ai/api/v1/models | python -c "import json,sys; d=json.load(sys.stdin); f=[m['id'] for m in d['data'] if m['id'].endswith(':free')]; print(len(d['data']),'models,',len(f),'free')"
```

| Reading | Total models | Ending in `:free` |
|---|---|---|
| first | 431 | 19 |
| second | 430 | 18 |

**Disappeared between the two readings:** `z-ai/glm-5.2:free`

**Appeared:** none

This is the whole argument for `data/catalog.json` being regenerated by CI rather
than hand-written. A free-model table typed in August is fiction by October, and the decay is
measured in hours, not months. Every other list in this space is a snapshot with no timestamp on
the individual rows; this file is what a timestamp is worth.
