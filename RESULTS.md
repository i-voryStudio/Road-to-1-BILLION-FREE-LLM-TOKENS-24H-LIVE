# Full ranking

Generated by `bench/rank.py` on **2026-09-20** - do not edit by hand.

Quality is **imported** from official benchmarks (https://openrouter.ai/api/v1/models, fetched 2026-09-20). We do not run it ourselves. Everything else - quota, auth, privacy cost - is measured or read from the provider's own terms.

`Value` = `coding_index x log10(1 + daily_tokens / 500) x answered_rate x 1.25 if no key x 0.5 if degraded`. A brilliant model you may call 20 times a day loses to a decent one you may call 2,400 times, which is the whole point of ranking this way. `daily_tokens` is the smaller of the token cap and the request cap times 500, and its label says how we know it: MEASURED, DECLARED or DERIVED may be ranked; PAID-PLAN, UNKNOWN, DRAWN and DRAWN may not.

### The reasoning trap

A model that reasons can spend its entire token budget thinking and return an **empty message with HTTP 200**. The status code says success. There is no text in it. This is the single most expensive surprise on a free tier, because nothing looks wrong.

Each provider family takes a different switch, and some take none:

```
reasoning_effort                             gpt-oss family on Groq, Cerebras, Ollama and OpenRouter
chat_template_kwargs.enable_thinking         NVIDIA nemotron, on NVIDIA and via OpenRouter
enable_thinking                              Alibaba Qwen on DashScope
thinking.type                                z.ai GLM
```

Measured in the archived run: **5 empty 200s, 4 of them on models where no switch was set.**
